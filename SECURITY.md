# Security Policy

Do **not** open public issues for suspected security vulnerabilities across any `futileandstupid/*` repository.

Please submit vulnerability reports privately through **[GitHub Private Vulnerability Reporting on `futileandstupid/jezz`](https://github.com/futileandstupid/jezz/security/advisories/new)** (or the target repository's Security tab if reporting a repository-specific issue), including a minimal deterministic reproduction and impact summary.
