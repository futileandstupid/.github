# Contributing

Starter template repositories (`jezz-template-*`) and `jezz-showcase` are generated from or companion to **[`futileandstupid/jezz`](https://github.com/futileandstupid/jezz)**.

- Open defect reports, JBC rule calibrations, capability proposals, and pull requests centrally in **[`futileandstupid/jezz`](https://github.com/futileandstupid/jezz/blob/main/CONTRIBUTING.md)**.
- Template updates inside `futileandstupid/jezz/templates/` propagate automatically on tagged releases.
